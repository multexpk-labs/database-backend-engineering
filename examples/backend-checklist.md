# Backend Data-System Checklist

- [ ] Keys, relationships, constraints documented
- [ ] Indexes match measured query patterns
- [ ] Validation and authorization implemented
- [ ] Transaction boundaries explicit
- [ ] Retryable operations are idempotent where required
- [ ] Timeouts and bounded retries configured
- [ ] Monitoring and slow-query visibility available
- [ ] Backup verification and restore test completed
- [ ] Secrets excluded from source control
- [ ] Production data excluded from public examples
